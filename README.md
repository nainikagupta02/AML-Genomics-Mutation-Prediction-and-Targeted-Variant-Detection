# AML Genomics: Mutation Prediction and Targeted Variant Detection

## Projects

- **[`beataml_modeling/`](beataml_modeling/)** — Patient-grouped elastic-net
  (and marker-logistic, random-forest, majority-baseline) models predicting
  FLT3-ITD and NPM1 mutation status from BEAT-AML RNA-seq. Development/
  finalization are leakage-audited and locked; see `audit_results.py`.
- **[`tcga_laml_validation/`](tcga_laml_validation/)** — External validation
  of the frozen BEAT-AML elastic-net models on 151 TCGA-LAML patients, with
  no refitting, retuning or recalibration (AUROC 0.873 FLT3-ITD, 0.964 NPM1).
  Imports `beataml_modeling/workflow.py` directly, so both projects must stay
  siblings on disk (as they are here).
- **[`beataml_mlops/`](beataml_mlops/)** — Operational layer around the two
  projects above: MLflow logging/registry for the frozen models, a gene-level
  drift analysis quantifying BEAT-AML→TCGA distribution shift and its effect
  on each model's linear predictor, a per-sample out-of-distribution monitor,
  and a PyTorch MLP benchmarked against the elastic-net on identical CV folds
  and the same frozen TCGA evaluation.
- **[`aml_variant_demo/`](aml_variant_demo/)** — A separate, laptop-scale
  Nextflow pipeline recovering known AML cell-line events (FLT3-ITD,
  RUNX1-RUNX1T1, PML-RARA) with a preregistered negative control, using
  samtools, getITD, kallisto and Pizzly.

## What's excluded here

Large, regenerable or non-original files are excluded via `.gitignore` rather
than committed — see each subproject's README for how to rebuild them:

- `tcga_laml_validation/data/counts/` (~610MB of raw GDC downloads) —
  `acquire.py` re-fetches and checksum-verifies these from the saved manifest.
- `tcga_laml_validation/results/aligned_raw_counts.npy` and
  `beataml_modeling/results/counts_input.npy` — frozen numeric inputs,
  rebuilt by rerunning each project's prepare/develop phase.
- `aml_variant_demo/work/` (Nextflow's own scratch/cache directory) and
  `aml_variant_demo/track2_discovery/` (multi-GB public reference-genome
  downloads and kallisto/pizzly indices) — not original work, and far too
  large for git; `aml_variant_demo/INSTALL.md` covers rebuilding them.
- `beataml_mlops/mlruns/` — generated by `log_models.py`; a local MLflow
  store, not needed to read or rerun the code.

Everything else — all code, configs, small results (CSV/JSON/PNG), the
`.joblib` model files (each under 2MB), and every README — is committed.
